# AI Search CLI

## 프로젝트 개요

개발자가 구현하려는 기능이나 해결하려는 문제를 텍스트로 입력하면,
AI가 직접 답을 생성하는 대신 **실제 웹 검색 결과를 수집하고 분석**해서
마크다운 파일로 정리해주는 CLI 도구입니다.

---

## 왜 만드는가

기존 AI 도구는 학습 데이터 기반으로 답을 생성하기 때문에
최신 정보가 부족하거나, 출처가 불분명하거나, 보안 이슈를 놓치는 경우가 있습니다.
그 때문에 구현하고자 하는것을 명쾌히 구현하지 못 합니다.

이 도구는 AI가 답을 "만들어내는" 게 아니라,
**검색 결과라는 실제 데이터를 가져온 뒤 AI가 그걸 분석하고 정리**하는 방식으로 동작합니다.
QUARK ENGINE는 요약자이지 창작자가 아닙니다.

---

## 동작 방식

1. **입력 해석**
   사용자가 자연어로 입력하면, ai가 이를 구조화된 스키마로 변환합니다.
   목표(goal), 도메인(domain), 관련 기술(possibleTechs), 다양한 검색어(searchQueries)로 분해합니다.

2. **다각도 검색**
   검색알고리즘이
   생성된 검색어 목록을 기반으로 한국어/영어 검색을 동시에 수행하고,
   관련 웹 페이지의 내용을 수집합니다.
   

3. **AI 분석 및 정리**
   수집된 원본 데이터를 AI가 분석해서 다음 항목을 마크다운 파일로 정리합니다.
   - 핵심 개념 및 구현 방법
   - 단계별 구현 가이드
   - 보안 이슈 및 주의사항
   - 참고 출처 링크

4. **파일 출력**
   정리된 내용은 `.md` 파일로 저장되어 AI 코딩 도구(Cursor, Copilot 등)가
   컨텍스트로 참조할 수 있는 형태로 제공됩니다.

---

## 사용 예시
```bash
quark api
quark "JWT 로그인 구현 보안 이슈"
```

현재는 위 명령어를 실행하면 AI가 검색용 `SearchInput` 스키마를 먼저 생성하고,
이후 검색 코어가 그 구조를 기반으로 실제 웹 검색을 수행하도록 연결하는 단계입니다.

---

## 기술 스택

- **Runtime**: Node.js
- **AI Schema Builder**: OpenAI Responses API with structured JSON output
- **Default model**: `gpt-5.4-nano-2026-03-17`
- **역할 분리**: 검색 알고리즘(수집) + AI(분석/요약/변환)
- **출력 형식**: Markdown

---

## 현재 구현 상태

- 자연어 입력을 `SearchInput` 스키마로 변환하는 AI 해석 단계 구현
- `quark api` 명령으로 로컬 설정 파일에 OpenAI API 키 저장
- 실제 웹 검색 수집 단계는 아직 미구현
- 인증은 `OPENAI_API_KEY` 환경변수 또는 `quark api` 저장값을 사용함
